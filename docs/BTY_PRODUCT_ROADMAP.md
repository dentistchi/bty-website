## What each milestone means (why, not how)

### 1. Learning Engine

The third Reality Engine. Same contract as Action and Event:

`verify → award() → new_core_xp → reproject(new_core_xp)`

Learning does not "give XP" for watching content. It verifies that learning happened in reality.

### 2. TODAY Home

The center of BTY. Not a dashboard — a daily bridge back to the real world.  
All roads (Action, Event, Learning) return here.

### 3. Reality Event UI

Backend for Event Engine exists; users cannot feel it yet.  
Leaders create events; members scan to verify attendance. No UI = no product value.

### 4. Avatar Evolution (12)

Avatar is earned growth made visible. This milestone is the **felt** progression — not outfit cosmetics.

### 5. TII / Team Culture

Team Index as organizational culture signal. Deferred until individual reality engines and TODAY are solid.  
Do not scope-creep org/TII into earlier engine slices.

## Success criteria (roadmap complete)

The roadmap is done when a user can:

1. Open TODAY and see what to do in the real world (Action / Event / Learning)
2. Complete verified actions across all three Reality Engines
3. See Avatar reflect accumulated verified growth
4. Participate in team culture signals grounded in verified behavior (TII)
