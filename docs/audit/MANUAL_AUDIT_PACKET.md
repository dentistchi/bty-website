## Instructions
1. **Run the entire SQL file without edits** in the trusted psql runner (read-only). It returns one
   JSON value carrying the packetId, every component digest, `expectedRuntimeQueryDigest`, and the
   measured `actualRuntimeQueryDigest`.
2. **Export exactly one result** (the single `audit` value). Do not edit the JSON/CSV.
3. **Run the comparator.** It recomputes the packet identity from the checked-in files, verifies it
   matches the manifest, verifies the export's `actualRuntimeQueryDigest == expectedRuntimeQueryDigest`
   (the statement that ran is the generated one), then compares effects.
4. **Stop on any `PACKET REJECTED`** (including `EXECUTED QUERY DIGEST MISMATCH`) — no trusted
   comparison occurred. Re-run the UNEDITED generated SQL in the trusted runner and re-export.
5. **Return the machine report** (per-migration A/D/E, grouped by final authority; `submit_followup`
   under `20260729`).
6. **This authorizes no repair or schema change.** An `A` candidate is not permission to
   `supabase migration repair`, `db push`, or apply any migration (single live DB = production).
